This is a university project simulating a group of wolves that communicate to catch randomly moving sheep on a grid map.
The wolves only know the relative position of prey within their vision range and the position of other wolves.
Given that information, two wolves must sorround a sheep to catch it and score a point.
We've implemented a new coordination mechanic - sound.
Each wolf can howl to send signals to other wolves as well as hear other wolves.
In short simplification, whenever a wolf sees a prey, it asks for help.
The closest wolves, which see no prey themselves, can lend aid to wolves who need it.
